# printf404.github.io

Personal blog — minimal, fast, no tracking.

## Pages
- `index.html` — home (post list + about)
- `post.html`  — sample article page
- `404.html`   — 404 with a mini game (catch blue / dodge red)

## Style
- Pure HTML + CSS + vanilla JS, no frameworks
- Hosted on GitHub Pages
- Dark, monospaced, accent: ice blue #4cc9f0

## How to add a post
1. Copy `post.html` → rename to your slug, e.g. `my-new-post.html`
2. Edit title, date, content
3. Add an entry to the `posts` array in `index.html` (date / title / tag / excerpt / url)
4. Commit & push — GitHub Pages deploys automatically
