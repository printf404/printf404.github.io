回到纯文本

这一版的做法朴素得离谱：一个 index.html，手写文章列表；一篇文章一个 .html；样式全部内联或放在同一个 <style> 里。没有构建步骤，没有 npm install，没有版本冲突。

改一个字就提交推送，GitHub Pages 自动部署。从编辑到上线，30 秒内。

# 我的写作流程
$ vim post.html
$ git add . && git commit -m "写点东西"
$ git push
# 完事。

少即是多

整个站点加起来不到 100KB，打开速度永远小于 100ms，在任何设备上都能正常阅读。这本身就是一种美学。
